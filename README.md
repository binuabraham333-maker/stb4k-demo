# stb4k Demo

**All demo content is made by stb4k.** Every video, sound, poster, channel logo and subtitle in this repository was
generated by stb4k for the STB4K player (iPhone, iPad, Apple TV). It contains no films, TV channels, music, sounds,
pictures or streams from anyone else.

Published with GitHub Pages:

- Playlist: https://binuabraham333-maker.github.io/stb4k-demo/demo.m3u
- Support: https://binuabraham333-maker.github.io/stb4k-demo/support.html
- Privacy Policy: https://binuabraham333-maker.github.io/stb4k-demo/privacy.html
- Minimum version: https://binuabraham333-maker.github.io/stb4k-demo/min-version.json — the app (build 35 and later)
  reads it at start; a lower build shows only "message" and an App Store button. Optional "url": the App Store link.
  Raise "minBuild" only when every user must update.

## What is in the Demo

| Item | Kind | What it is |
|---|---|---|
| stb4k Demo 1 | Live channel (HLS) | Colour bars, a short beep every second |
| stb4k Demo 2 | Live channel (HLS) | Moving test pattern, a beep every two seconds |
| stb4k Demo 3 | Live channel (HLS) | Moving colours, a low beep every three seconds |
| stb4k 5.1 Audio Test | Film (MP4, 1:38) | 5.1 sound: Front Left, Front Right, Centre, Subwoofer, Surround Left, Surround Right in turn, each named on screen |
| stb4k Two Audio Languages | Film (MP4, 1:10) | Two audio tracks: English (one low beep a second) and Malayalam (two high beeps) |
| stb4k English Subtitles | Film (MP4, 1:16) | An English subtitle track with ten lines |
| stb4k Demo Series S01E01–E03 | Series (MP4, 0:40 each) | Episodes Red, Green and Blue |

All videos are 1920 × 1080, H.264 with AAC sound. The live channels repeat a one-minute loop for four hours (a static
web site cannot send a real live stream); the clock in their corner is the time in that loop.

## How it was made

- Pictures: FFmpeg's built-in generators (SMPTE colour bars, test pattern, colour gradients) — no camera, no footage.
- Sounds: sine-wave beeps and tones calculated by FFmpeg (`aevalsrc`) — no music or recordings.
- Text, posters and logos: drawn by `tools/render.swift` with the open font **Atkinson Hyperlegible**
  (© 2020 Braille Institute of America, SIL Open Font License 1.1, see `tools/Atkinson-Hyperlegible-OFL.txt`).
  The font files are not part of this repository; only pictures made with them are.
- The STB4K logo (`images/stb4k-logo.png`) belongs to stb4k.
- Everything can be built again with `tools/build.py` (FFmpeg and Swift on a Mac).

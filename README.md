# STB4K Demo

Free, legal demo content for the STB4K player (iPhone, iPad, Apple TV), published with GitHub Pages:

- Playlist: https://binuabraham333-maker.github.io/stb4k-demo/demo.m3u
- Support: https://binuabraham333-maker.github.io/stb4k-demo/support.html
- Privacy Policy: https://binuabraham333-maker.github.io/stb4k-demo/privacy.html

Only open movies by the Blender Foundation under Creative Commons licences. Every title in the playlist carries its
credit, so it shows inside the app. No IPTV channels, no paid or copyrighted TV content.
